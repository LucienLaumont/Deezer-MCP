Deezer MCP

Un serveur MCP qui expose le catalogue public Deezer à des clients comme Claude — recherche, previews audio, fiche artiste composite et génération de playlist par ambiance.

En conditions réelles

Une vraie session Claude, tapée en direct, sans montage scénarisé : recherche, fiche artiste enrichie, puis génération d'une playlist par ambiance à partir d'une simple description en langage naturel.

9 tools

Un mapping fin sur l'API Deezer pour les usages simples, et deux tools composites pensés pour réduire les allers-retours du modèle plutôt que du 1-endpoint-1-tool.

Playlist par ambiance

l'intelligence reste côté modèle

Pas de NLP côté serveur : ces deux tools fournissent juste la matière première (genres, charts) pour que le modèle compose lui-même une sélection cohérente avec une description libre ("ambiance road trip de nuit", "énergique pour courir"...).

list_genres()Genres Deezer disponibles, pour cibler un chart
get_chart_tracks(genre_id, limit)Titres populaires du moment, globalement ou par genre

Sous le capot

Quelques décisions qui ne se voient pas dans une démo mais qui tiennent le serveur debout.

Erreurs toujours en HTTP 200

Deezer répond 200 même en cas d'erreur logique — chaque requête vérifie systématiquement la clé error du payload plutôt que de se fier au status code.

Résolution par popularité, pas par pertinence

Chercher "Justice" par nom peut renvoyer un homonyme à 1 000 fans avant le vrai groupe à 800 000 — la résolution retient le candidat avec le plus de nb_fan, pas le premier résultat.
